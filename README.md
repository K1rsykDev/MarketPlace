# PlayerHub Marketplace

Повноцінна dark-theme платформа для оголошень спільноти гравців з ролями, профілями та адмін-панеллю.

## Можливості
- Реєстрація, авторизація та збереження сесій (Flask-Login).
- Профіль з NickName, Discord, роллю та списком власних оголошень.
- Створення, редагування та видалення оголошень (категорія, назва, ціна/бюджет, опис, Discord).
- Головна сторінка з фільтрацією по категоріях та сортуванням за датою/ціною.
- Рольова модель: Учасник, Модератор, Адміністратор + створення нових ролей через адмін-панель.
- Адмін-панель для перегляду всіх оголошень, модерації та керування ролями користувачів.
- Темна сучасна стилізація та адаптивна верстка.

## Запуск
1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустіть сервер (SQLite використовується за замовчуванням):
   ```bash
   python app.py
   ```
3. Відкрийте [http://localhost:5000](http://localhost:5000) у браузері.

На першому запуску автоматично створюються базові ролі: Учасник, Модератор, Адміністратор.
